## Tabs, hints and going to a definition

<video controls muted playsinline preload="none" width="960" style="max-width: 100%; height: auto;"
  poster="images/definition-poster.jpg" src="../demo/go-to-definition.mp4">
  <a href="../demo/go-to-definition.mp4">Download the video</a>
</video>

A program in two files: a helpers module saved on the Pico, and a program that imports it.
Resting the pointer on a name shows where it's defined, and Ctrl-click goes there, opening the other file from the Pico.
See [Tabs and programs in several files](../help/tabs.html) and [Finding where things are defined](../help/definitions.html).
