Lesson 1: Blink

Every Pico has a small LED on the board. This program makes it blink ten times. Click Run and choose your Pico.

Then try making it blink faster: change 0.5 to 0.1 and run it again. What happens if you misspell led on line 7?

from machine import Pin import time led = Pin("LED", Pin.OUT) for i in range(10): led.toggle() print("blink", i) time.sleep(0.5) print("done")
