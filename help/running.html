Running and stopping

Run sends the program in the editor to the Pico and runs it. Its output appears under Output as it arrives. Stop interrupts a program that is still running, such as one with a while True: loop.

While a program is running, a Type to your program box appears under its output. If your program uses input(), type your answer there and press Enter. The Pico shows what you typed in the output. You can type before the program asks; it reads your line when it gets to input(). The same box appears under the REPL when a line you typed there is running.

Each run starts afresh: variables from earlier runs are cleared, but files on the Pico are kept. Run always uses what's in the editor, not a file saved on the Pico.

Tips

  • The Tab key indents by four spaces.
  • On a Raspberry Pi Pico or Pico 2, the LED on the board is Pin("LED", Pin.OUT).
