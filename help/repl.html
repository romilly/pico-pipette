The REPL and variables

The REPL

The REPL box under the output lets you type Python and run it on the Pico straight away, a line at a time. Type an expression, such as 2 ** 10, and press Enter to see its value.

  • The REPL shares variables with the program you last ran, so after Run or Stop you can look at them, change them, or call your functions. The Variables table updates after each line.
  • After a line ending in :, or with a bracket still open, Enter starts a new line (indented for you). Press Enter on an empty line to run the whole block. Shift+Enter always starts a new line.
  • ↑ and ↓ bring back earlier lines. Stop interrupts a line that's still running.
  • Running a program starts afresh, clearing the REPL's variables too.

Variables

When your program finishes, fails or is stopped, the Variables table shows the variables it left behind, with their types and values. After pressing Stop in a loop, for example, you can see how far the loop had got.

  • Only variables at the top level of your program are shown, not those inside functions.
  • Modules, functions and classes are left out, and long values are shortened.
