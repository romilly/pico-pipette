Finding where things are defined

Rest the pointer on a name, such as a function or variable, and Pipette tells you which line defines it. Ctrl-click the name (Cmd-click on a Mac), or put the cursor in it and press F12, to go there.

  • It follows your own code: functions, classes, variables, function parameters, loop variables and self. attributes. Inside a function, its own variables come first, as they do when Python runs it.
  • If the name comes from another file, as double does after from helpers import double or in helpers.double(2), Pipette opens that file at the definition. It uses the file's tab if it's open, or reads it from the Pico (from the main folder, then /lib), so connect first.
  • Some names have no Python file to show: things built into MicroPython, like print or machine, and packages installed in compiled form (.mpy files). Pipette says so.
  • For something like led.on(), Pipette can't tell where on comes from without running the program, because it depends on what led holds.
