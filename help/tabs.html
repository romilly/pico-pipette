Tabs and programs in several files

Each open file has its own tab above the editor, so you can look at several files and switch between them. Each tab keeps its own code, undo history and error marks.

  • Click a tab to show it. + starts a new, empty file: type its name in the box beside Open….
  • A ● on a tab means it has changes that aren't saved. × closes a tab, asking first if its changes aren't saved.
  • The name box, Save to computer, Save to Pico, Save as main.py and Run all work on the tab showing.

Programs in more than one file

If main.py says import helpers, the Pico runs the helpers.py that's saved on the Pico, not what's in its tab. So when you change helpers.py, use Save to Pico on its tab before you run main.py. If you forget, Pipette reminds you when you click Run.

If an error happens inside a file that's open in another tab, Pipette switches to that tab and marks the line.
