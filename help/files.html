Files

On your computer

Open… opens a file in a new tab. Save to computer saves the tab showing, using the name in the box beside it. In Chrome and Edge it saves back to the file you opened; in other browsers it downloads a copy.

On the Pico

  • Click a file in the Pico files panel to open it in a new tab (or go to its tab, if it's open already). Click a folder to go into it, and .. to come back.
  • Save to Pico saves the tab showing into the folder shown, using the name in the box.
  • Save as main.py saves it as /main.py. The Pico runs main.py whenever it powers up, so your program will run on its own, even from a phone charger or battery. Connecting with Pipette stops it again.
  • ✕ (shown when you point at a file) deletes it, after asking. This can't be undone. Folders must be empty before they can be deleted.
  • New folder creates a folder, and ↻ refreshes the list.
